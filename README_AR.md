# ALQOUD TOOLS — مشروع Flutter

## ما يحتويه
- حاسبة الأرباح والخصومات والأقساط والجملة والتجزئة.
- حفظ سجل فواتير بسيط محلياً باستخدام SharedPreferences.
- الأدوات الحسابية تعمل دون إنترنت.
- لا يوجد خادم أو قاعدة بيانات سحابية.

## المتطلبات
- Flutter SDK حديث.
- Android SDK وAndroid build tools.
- اتصال إنترنت لتنزيل الحزم وبناء التطبيق أول مرة.

## التشغيل
```bash
flutter doctor
flutter pub get
flutter run
```

## بناء APK
```bash
flutter build apk --release
```
الناتج:
`build/app/outputs/flutter-apk/app-release.apk`

## بناء AAB لمتجر Google Play
```bash
flutter build appbundle --release
```
الناتج:
`build/app/outputs/bundle/release/app-release.aab`

## الإعلانات
لم يتم تفعيل الإعلانات الحقيقية بعد. قبل النشر:
1. أنشئ حساب AdMob وفق شروط العمر والبلد والدفع.
2. أنشئ تطبيق Android ووحدات إعلانية في AdMob.
3. أضف معرف التطبيق إلى AndroidManifest.xml ومعرفات الوحدات إلى كود التطبيق.
4. اختبر باستخدام معرفات الإعلانات التجريبية الرسمية أولاً.
5. لا تنقر على إعلاناتك ولا تطلب من الآخرين النقر عليها.

إضافة SDK الإعلاني وحدها لا تضمن قبول التطبيق أو تحقيق الدخل. يجب إعداد صفحة خصوصية وإفصاحات البيانات والالتزام بسياسات Google Play وAdMob.

## ملاحظات مهمة
- هذا مشروع بداية قابل للتطوير، وليس إصداراً منشوراً أو ملف APK/AAB جاهزاً.
- لا توجد خدمة سيرفر مطلوبة للوظائف الحالية.
- الإعلانات تتطلب الإنترنت.
- بيانات الفواتير محفوظة على الجهاز وقد تضيع عند حذف التطبيق ما لم تنسخ احتياطياً.
- قبل النشر، أكمل الاختبارات، أيقونة التطبيق، اسم الحزمة الفريد، توقيع الإصدار، سياسة الخصوصية، وتصنيف المحتوى.
- على من هم دون السن المطلوب لحسابات المطور/الإعلانات أن يستعين بولي أمر وفق شروط Google.
